## myd — document review & rich explainers

When the user wants to review, comment on, or discuss a Markdown file — or asks for a plan/design/explainer they'll look at — write it to disk and use `myd` (on PATH): `myd view "/abs/file.md" --wait` opens the viewer and blocks until they click Done Reviewing; then `myd comments FILE` and `myd reply/resolve`. Load the **myd** skill (`/myd`, or `~/.claude/skills/myd/SKILL.md` · `~/.codex/skills/myd/SKILL.md`) for the workflow, block editing, rich fences (mermaid / vega-lite / html), and the annotation inventory; `myd help` / `myd guide <topic>` also work.
